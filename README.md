# 一键双语翻译

中英网页翻译工具：保留原文、逐段显示译文，也可以只翻译选中的一句话。

## 开始使用

需要 Chrome 140+ 和翻译服务的 API Key。

1. 在 `chrome://extensions` 开启开发者模式，加载本仓库的 `chrome-extension/`。
2. 在设置中填写 API Key，点击「保存并测试」。默认使用 DeepSeek，也可选择其他服务。
3. 打开网页，点击扩展面板中的「翻译网页」。点击「恢复原文」撤下译文。

仓库包含构建产物。代码更新后，重新加载扩展并刷新网页。

## 日常操作

- **整页翻译**：正文逐段对照，短按钮和导航标签显示行内译文。页面角落显示加载动画和进度，完成后显示绿色勾号；请求失败时保留已有译文，点击「重试」继续。
- **划词翻译**：在面板启用划词，选中文字后点击「翻译」。长原文默认折叠，支持复制译文、重试和 Esc 关闭。
- **英语朗读**：英语选区可直接点击「朗读」；中文选区翻译后可朗读英语译文。默认使用系统英语声音，Edge TTS 的配置见[本地服务说明](tools/edge-tts/README.md)。
- **阅读设置**：面板底部「阅读与发音」调整译文样式、字号、行距和声音。自动划词设置只决定下次开启整页翻译时的默认行为。
- **快捷入口**：右键菜单翻译或朗读选区；`Alt+Shift+D` 翻译/恢复整页，`Alt+Shift+S` 翻译选区。macOS 使用 `Control+Shift+D/S`。

## 使用范围

- 划词最多 12,000 字符，英语朗读最多 6,000 字符；关闭浮层或更换选区会取消对应请求和朗读。
- 网页文字发送给你选择的服务，可能产生费用。API Key 和语音令牌仅保存在本机的扩展存储中。
- 支持可访问的 iframe 和开放 Shadow DOM；跨域嵌入内容可能需要在阅读设置中授权。
- 浏览器受限页面、PDF、图片文字和闭合 Shadow DOM 无法通过普通网页 DOM 翻译。代码块和编辑区默认跳过。
